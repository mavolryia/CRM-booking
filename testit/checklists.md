### Функциональный чек-лист для формы регистрации Регистрация

*Тест-кейс* · Priority: High · Tags: функциональный

**Шаги:**

1. Ввести %валидный_емейл + %валидный_пароль + кнопка Зарегистрироваться
2. Ввести пробел перед %валидный_емейл + %валидный_пароль + кнопка Зарегистрироваться
3. Ввести пробел после %валидный_емейл + %валидный_пароль + кнопка Зарегистрироваться
4. Ввести емейл без @ (test.gmail.com) + %валидный_пароль + кнопка Зарегистрироваться
5. Ввести @ в поле ввода емейл + %валидный_пароль + кнопка Зарегистрироваться
6. Ввести емейл без домена (test@)+ %валидный_пароль + кнопка Зарегистрироваться
7. Ввести емейл без имени пользователя (@gmail.com) + %валидный_пароль + кнопка Зарегистрироваться
8. Ввести емейл с пробелом внутри (test @gmail.com)
9. Отправить пустое поле емейла + %валидный_пароль + кнопка Зарегистрироваться
10. Ввести только пробелы в поле емейла + %валидный_пароль + кнопка Зарегистрироваться
11. Ввести в поле емейла ранее зарегистрированный емейл + %валидный_пароль + кнопка Зарегистрироваться
12. Ввести %валидный_емейл + пароль 8 символов (сasd12345) + кнопка Зарегистрироваться
13. Ввести %валидный_емейл + пароль 7 символов (asd12345) + кнопка Зарегистрироваться
14. Ввести %валидный_емейл + пустое поле пароля + кнопка Зарегистрироваться
15. Ввести %валидный_емейл + пароль из пробелов + кнопка Зарегистрироваться
16. Ввести %валидный_емейл + пароль, содержащий спецсимволы (user@1234)
17. Ввести %валидный_емейл + пробел перед %валидный_пароль + кнопка Зарегистрироваться
18. Ввести %валидный_емейл + пробел после %валидный_пароль + кнопка Зарегистрироваться
19. Убедиться, что посте успешной регистрации пользователь перенаправляется на страницу Дашборд
20. Убедиться, что роли (админ, менеджер) отображаются на странице Дашборд согласно требованиям (первый зарегистрированный- админ, последующие- менеджеры)

### Сессия и выход из системы

*Чек-лист* · Priority: High · Tags: функциональный

**Шаги:**

1. Находясь на странице Дашборда в авторизовнной сессии нажать кнопку браузера Назад, затем вренуться на страницу Дашборда с помощью кнопки браузера Вперед
2. Находясь на странице Дашборда в авторизовнной сессии перезагрузить страницу
3. Находясь на странице Дашборда в авторизовнной сессии нажать кнопку выйти
4. После выхода из авторизованной сессии перезагрузить страницу
5. После выхода из авторизованной сесии попытаться вернуться на Дашборд с помощью кнопки браузера Назад
6. В LocalStorage подменить значение токена на случайный набор символов и перезагрузить страницу
7. В LocalStorage подменить значение токена на токен с истекшим сроком и перезагрузить страницу

### GUI логин/регистрация

*Общие шаги* · Priority: Highest · Tags: gui

**Шаги:**

1. Перейти на страницу логина/регистрации localhost:5173/login
   - Ожидаемый результат: Страница открывается, содержимое доступно для просмотра, отображается корректно
2. Нажать кнопку регистрация
   - Ожидаемый результат: Цвет кнопки меняется, открывается модуль для регистрации в системе
3. Изучить модуль Регистрация
   - Ожидаемый результат: В модуле присутствуют поля емейл и пароль. В полях отображены плейсхолдеры с правилами валидации полей. Кнопка Зарегистрироваться кликабельная
4. Вести любые данные в поле ввода емейла модуле Регистрации
   - Ожидаемый результат: Поле доступно для ввода данных, введенные данные отображаются корректно
5. Вести любые данные в поле ввода пароля в модуле Регистрация
   - Ожидаемый результат: Поле доступно для ввода данных, данные при вводе маскируются маской
6. Нажать на кнопку Вход
   - Ожидаемый результат: Цвет кнопки меняется, открывается модуль для входа в систему
7. Изучить модуль Вход
   - Ожидаемый результат: В модуле присутствуют поля емейл и пароль. В полях отображены плейсхолдеры с правилами валидации полей. Кнопка Войти кликабельная
8. Вести любые данные в поле ввода емейла в модуле Вход
   - Ожидаемый результат: Поле доступно для ввода данных, введенные данные отображаются корректно
9. Вести любые данные в поле ввода пароля в модуле Регистрация
   - Ожидаемый результат: Поле доступно для ввода данных, данные при вводе маскируются маской
10. Убедиться, что при переключении между Вход и Регистрация поля ввода очищаются
   - Ожидаемый результат: При переключении между Вход и Регистрация поля ввода очищаются и отображаются корректные плейсхолдеры
